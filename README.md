# 无畏时刻 · 本地视频墙

## NAS / Docker 适配版

本 fork 新增 NAS 部署入口，原版 Windows 用法保留。详见 [NAS 部署说明](NAS部署说明.md)。

- 支持 nas-video-archiver 0.2.0 的原始加密数据库历史快照，校验后解密、转换 Windows 路径并合并全部历史。
- 没有数据库时仍可扫描视频；后续上传元数据会自动补齐分类。视频/封面和元数据均只读。
- 单 worker、启动扫描、默认每 120 秒自动刷新；索引、收藏与标签放独立持久化目录。
- NAS 模式禁止删除、回收站修改、导出及越界目录访问；容器不能写入录像目录，不跟随符号链接。
- 家庭局域网服务，不应直接暴露公网。容器入口为 `nas_server.py`，不再使用 Windows 的 `start.bat`。

以下为上游原版功能与 Windows 使用说明；其中删除、导出、任意数据目录切换功能在 NAS 适配入口中被禁用。

> 给《无畏契约》(VALORANT) 玩家用的**本地录像管理器**。
> 自动读取游戏客户端录制的「无畏时刻」视频，解密出对局数据，用一个漂亮的网页界面浏览、筛选和播放你的高光时刻。

**完全本地运行 · 不上传任何数据 · 无需登录 · 免费开源**

---

## 为什么需要它

游戏客户端自带的「无畏时刻」页面有几个痛点：

- 视频一多就卡，滚动加载很慢
- 不能按英雄 / 地图 / 日期组合筛选
- 想找某一场的录像翻半天
- 收藏、打标签、整理，都没地方下手

这个工具把本地录像做成一个**本地网页**，打开秒开，筛选、搜索、播放、整理全部到位。

## 快速开始

### 环境要求

- **Windows 10 / 11**
- **Python 3.9+**（[下载](https://www.python.org/downloads/)，安装时勾选 `Add Python to PATH`）
- 装了《无畏契约》国服客户端，且用「无畏时刻」录过视频

### 安装

```bash
git clone https://github.com/<你的用户名>/valorant-moments.git
cd valorant-moments
```

或直接 **Download ZIP** 解压。

### 启动

**方式一：双击（推荐）**

双击 `start.bat`（或 `启动.bat`）。首次运行会自动安装依赖。

**方式二：命令行**

```bash
pip install -r requirements.txt
python app.py
```

启动后浏览器自动打开 **http://127.0.0.1:8765**

> 命令行窗口不要关，关掉就等于停止服务。

### 首次使用

程序会自动查找默认目录：

```
C:\Users\<你的用户名>\AppData\ACLOS\aclos-highlight
```

找到就直接扫描。**没自动找到**的话，点右上角「**数据目录**」手动选这个路径。

## 工作原理

### 数据从哪来

游戏客户端把录像存在 `AppData\ACLOS\aclos-highlight\`，但对局信息（英雄、地图、比分、KDA）是**加密存储**的，在：

```
%APPDATA%\ACLOS\WonderfulDb\<openid>          # 主账号
%APPDATA%\ACLOS\WeGameWonderfulDb\<gopenid>   # WeGame 账号
```

### 怎么解密

用从客户端逆向分析得出的规则：

```python
key = sha256(openid).hexdigest()[:32]   # AES-256
iv  = sha256(openid).hexdigest()[:16]
# AES-CBC 解密，磁盘上是 hex 编码
```

WeGame 账号是 AES-128 变体（key 和 iv 都取 `[:16]`）。

### 处理流程

```
读取加密库 → 解密 → 提取对局元数据
        ↓
扫描视频目录 → 匹配 → 关联英雄/地图/战绩
        ↓
生成 library.json（本地索引）
        ↓
FastAPI 提供接口 → 网页展示
```

**全程只读游戏文件**，不修改、不移动任何原始录像（除非你主动点删除）。

### 项目结构

```
valorant-moments/
├── app.py              FastAPI 服务 + 所有接口
├── datasource.py       查找并解密客户端数据库
├── library.py          扫描视频目录、构建索引
├── mapping.py          英雄/地图/模式 → 中文名 + 官方图片地址
├── web/
│   ├── index.html      页面结构
│   ├── app.js          前端逻辑（渲染、筛选、播放器）
│   └── style.css       样式
├── start.bat           Windows 启动脚本
├── config.example.json 配置文件示例
└── requirements.txt    依赖
```

## 配置

第一次运行会自动生成 `config.json`，也可以手动编辑：

```json
{
  "root": "C:\\Users\\你的用户名\\AppData\\ACLOS\\aclos-highlight",
  "port": 8765,
  "host": "127.0.0.1",
  "open_browser": true
}
```

| 字段 | 说明 |
|---|---|
| `root` | 录像根目录，留空则自动查找 |
| `port` | 服务端口，被占用就改成 8766 之类 |
| `host` | 默认 `127.0.0.1`，只有本机能访问 |
| `open_browser` | 启动后自动打开浏览器 |

## 常见问题

<details>
<summary><b>双击 start.bat 一闪而过 / 报错</b></summary>

先确认装了 Python：

```bash
python --version
```

提示找不到就重装 Python 并勾选 `Add Python to PATH`，或用完整路径运行：

```bash
"C:\Users\你的用户名\AppData\Local\Programs\Python\Python313\python.exe" app.py
```
</details>

<details>
<summary><b>页面打不开 / 一直转圈</b></summary>

1. 检查命令行窗口是否还开着
2. 浏览器打开 http://127.0.0.1:8765
3. 端口被占用：改 `config.json` 里的 `port`
</details>

<details>
<summary><b>视频列表是空的</b></summary>

1. 点右上角「**数据目录**」，确认选的是 `AppData\ACLOS\aclos-highlight`
2. 点「**重新扫描**」
3. 确认游戏里确实录过视频（客户端「无畏时刻」页面能看到）
</details>

<details>
<summary><b>有些视频显示「文件已缺失」</b></summary>

客户端索引里有记录但磁盘上文件没了。点「**检查文件**」可以批量清理这些记录。
</details>

<details>
<summary><b>视频没声音 / 打不开</b></summary>

少数视频用了浏览器不支持的编码。可以用「导出副本」后用 PotPlayer / VLC 播放。
</details>

<details>
<summary><b>游戏更新后英雄/地图名字不对</b></summary>

点「**重新扫描**」重建索引。如果还是不对，说明新英雄的内部代号变了，需要更新 `mapping.py` —— 欢迎提 Issue。
</details>

<details>
<summary><b>会修改我的游戏文件吗</b></summary>

**不会。** 程序只读客户端的加密数据库，视频文件也只读。唯一的写操作是你主动点「删除」时，把文件移到项目内的 `回收站/` 文件夹。
</details>

## 技术栈

- **后端**：Python 3 + FastAPI + uvicorn
- **加密**：pycryptodome（AES-CBC 解密客户端数据库）
- **前端**：原生 JavaScript + CSS（无框架、无构建步骤，改完刷新即可）
- **视频传输**：HTTP Range 流式传输，支持拖动进度条
